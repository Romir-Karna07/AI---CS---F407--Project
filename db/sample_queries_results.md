# Sample queries - results

Database: `db/manipur.db`. Generated by `python db/sample_queries.py`. `expected` comes from the raw partition files (independent parser), except where marked design.


## Q1 - How many records did the six dev partition files put into each data table?

```sql
SELECT 'soil_health', COUNT(*) FROM soil_health WHERE source_file IN ('soil_P1.json','soil_P2.json','rain_P1_imd.json','rain_P2_nasa.json','prod_P1.csv','prod_P2.csv') UNION ALL SELECT 'rainfall_monthly', COUNT(*) FROM rainfall_monthly WHERE source_file IN ('soil_P1.json','soil_P2.json','rain_P1_imd.json','rain_P2_nasa.json','prod_P1.csv','prod_P2.csv') UNION ALL SELECT 'crop_production', COUNT(*) FROM crop_production WHERE source_file IN ('soil_P1.json','soil_P2.json','rain_P1_imd.json','rain_P2_nasa.json','prod_P1.csv','prod_P2.csv')
```

Expected from: raw partition files (soil records; district-months of both rainfall files; production cells that hold a production value)

Result: **PASS**

| got | expected |
|---|---|
| ('soil_health', 367) | ('soil_health', 367) |
| ('rainfall_monthly', 3432) | ('rainfall_monthly', 3432) |
| ('crop_production', 811) | ('crop_production', 811) |
